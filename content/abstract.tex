\chapter*{Abstract}\label{cha:abstract}
As industrial machines produce an increasing amount of sensor data and rely on this it for predictive maintenance, the need for a dedicated framework to visualize the individual vibration measurements becomes increasingly important.\\ 
The combination of three individual concepts: time delay embedding, principle component analysis and sliding windows offers a powerful way of transforming raw vibration data into visually interpretable plots that reveal the structural changes triggered by mechanical faults. 
Existing offline implementations require the full signal history prior to computation and must recompute the covariance matrix and its eignedecomposition from scratch each time new observations arrives. \\
This thesis investigates wether an incremental, streaming version algorithm can preserve the diagnostic quality of the original method while reducing the computational overhead. The goal is to determine how time delay embedding, principal component analysis and the sliding window mechanism can be combined to support continuous, memory bounded processing of vibration data in real time.
Starting from the offline algorithm designed by \textcite{rakuschek2025visual}, the objective is to implement a C-based library that maintains running statistics,covariance matrix and dominant eigenvectors so that each incoming sample updates the existing principal components rather than triggering a full recomputation.\\
The resulting implementation is validated by comparing its produced values against a reference computation and evaluated on a vibration dataset comparing the plots produced by the incremental method to those of the original offline counterpart. Also the resulting plot quality under different settings like window size and other parameters is analyzed. \\
