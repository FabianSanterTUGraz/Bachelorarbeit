\subsection{Sampling Interval ($\Delta$t)}
Consistent sampling intervals are important factors in time series data. Large time jumps between consecutive consecutive measurements can introduce artificial anomalies. Therefore the dataset was validated by calculating the time differences between consecutive timestamps. 
The interval $\Delta t$ was calculated as : \\
\begin{equation}
    \Delta t_n = t_n - t_{n-1}, \qquad n = 2, \dots, N,
\end{equation}
Where $t_n$ is the time stamp of the file at time $n$ and $N$ is the number of files of a test run.
Using Python's NumPy min and max functions, the minimum and maximum $\Delta t$ were computed for each dataset.

All files contain 20,480 data points which means that the sampling within a file is consistent in all three test runs. The duration of the experiments varies with the longest test running for nearly 45 days and the shortest under 7 days. The median interval over all test runs is 10 minutes. In test 2 each interval is equal leading to an standard deviation of zero. In test 1 and 3 the mean and standard deviation are dominated by a few longer pauses in the experiment (caused by the resumption of the experiment in the next working day) the longest lasting about 6 days in test 1 and 7.5 hours in test 3. 
Considering that each file is processed as one window these irregularities do not affect the calculation of a single fingerprint if there are gaps in the dataset means that no fingerprint exists for that period of time.
