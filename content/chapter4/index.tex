\section{Summary}
This chapter was the main core of the thesis and detailed the realization of the transition of the algorithm from type 1 to type 2. This was achieved by combining time delay embedding, principal component analysis and a sliding windows. Standard libraries and programming language specific features where avoided to ensure maximum portability and to enable seamless integration across all C language family members.
