\section{Summary}
This chapter detailed the realization of the transition from type 1 to type 2 algorithm. This was achieved by combining time delay embedding, principal component analysis and a sliding window approach . Standard library utilities and programming language-specific features where deliberately avoided to ensure maximum portability to ensure seamless integration across all C language family members.
