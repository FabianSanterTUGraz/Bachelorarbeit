\chapter{Introduction}
Real-time anomaly detection is a crucial component of machine maintenance and operational security. It can help identify mechanical flaws or unexpected behavior long before complete machine failure occurs.
In practice, real-time anomaly detection is computationally challenging because as the incoming data continuously arrives over time, applying the standard offline analysis repeatedly introduces significant performance bottlenecks. The computational cost of algorithms used in this field, such as Principal Component Analysis (PCA), is the main bottleneck for real-time monitoring. One solution, proposed by the foundational paper for this thesis, combines Principal Component Analysis with Time Delay Embedding. The result of this method is a human-like fingerprint for plotting vibration signals. These plots are designed so that even an non-expert can quickly identify faulty vibrations of a machine.
The foundational paper for this work by Rakuschek (\cite{rakuschek2025visual}) demonstrates the algorithm using vibration data collected from a hydroelectric power plant.
