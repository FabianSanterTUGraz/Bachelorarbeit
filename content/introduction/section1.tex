\section{{Problem to solve}}
Plotting time series data which contains noise introduces the issue that when the amount of noise increases the identification of anomalies in the time series becomes harder.
Existing implementations use Principal Component Analysis in the combination with Time Delay Embedding for offline analysis. The main issue is that they can't process streaming data in real time due to the computational overhead of recalculating the principal component analysis in each iteration. The main task is to identify performance bottlenecks.
The algorithm should be extended to use incoming time series data to update existing principal components without full recomputation. Furthermore, a sliding window model should be adopted to handle endless data streams. Under this restriction, the analysis is restricted to the $k$ most recent observations, continuously reusing intermediate values as new data points arrive the window while expired ones are removed from the window.
A thesis specific requirement is to implement the algorithm platform independent using cross-platform programming language. The language should be a part of  the C language family and can be used in all languages of the C family with minimal changes to the source code.
