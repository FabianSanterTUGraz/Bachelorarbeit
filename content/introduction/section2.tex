\section{Contributions}
This thesis aims to transform the given type one algorithm and optimize it for streaming data. One of the requirements is that the Principal Component Analysis should be extended to be calculated on an sliding window which is adjustable in size. This means that new data points can be added to the time series while reusing the already calculated PCA. Instead of recomputing the covariance matrix, eigenvectors, and eigenvalues from scratch, the algorithm should efficiently update these values using the existing ones. Another main goal is the integration of a sliding window mechanism which bounds memory usage and ensures the responsiveness of the model to recent data patterns. Only the last $k-Elements$ from the time series should be used for the analysis also the partial results should be reused. Older points are discarded ensuring that the algorithm can adapt to changing signal patterns while holding a constant memory usage. \\
A thesis specific requirement is to implement the algorithm platform independent using cross-platform programming language. The language should be a part of  the C language family and can be used in all languages of the C family with minimal changes to the source code. For easy integration the result will be a small library with an API which lets the user easily integrate in already existing software projects.
The methodology section explaines the reasoning behind the choosing of the individual parts of the tech stack. This includes programming language and frameworks. Finally, the optimized implementation is evaluated by analyzing how the parameters window size, delay, stride and embedding dimensions impact the visual representation of the resulting fingerprint. 

Later in the Methology section the selection of each part of the tech stack like programming language and used frameworks will be justified.
