\subsection{Benchmarking against Reference Data}
\label{section:Against reference data}
To validate the implementation the tutorial by \cite{CheckForCorectness} is used as a reference, as it provides a full computation of an principal component analysis based on a small, deterministic dataset with 10 entries. The output of the incremental principal component analysis is compared step by step against the values reported in this reference. The sliding window is configured to span the entire input dataset $w = 10$ and the embedding dimension is set to $d =2$ corresponding to the two-dimensional input data additionally the time delay is set to $\tau = 0$ since the reference example does not involve any temporal lag. Since the incremental implementation is a single function which has an input and output and gives no intermediate results each part of the calculation has to be checked on its own which results are stored and then directly compared to the reference solutions.
