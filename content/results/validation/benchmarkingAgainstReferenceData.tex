\subsection{Benchmarking against Reference Data}
To validate the implementation the tutorial by \cite{CheckForCorectness} is used as a reference, as it provides a full computation of an principal component analysis based on a small, deterministic dataset. The output of the incremental principal component analysis is compared step by step against the values reported in this reference. The sliding window is configured to span the entire input dataset $w = 10$, the embedding dimension is set to $d =2$, corresponding to the two-dimensional input data and the time delay is set ti $\tau = 0$ since the reference example does not involve any temporal lag.
